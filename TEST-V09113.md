# Windows testing — v0.9.1.13

In a NEW extracted directory in Windows PowerShell, run the commands below in order:

```powershell
dotnet build YouTubeMusicToLidarr.csproj -c Release -r win-x64
dotnet run --project YouTubeMusicToLidarr.csproj -c Release -r win-x64 --no-build -- --self-test
dotnet publish YouTubeMusicToLidarr.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
.\publish\YouTubeMusicToLidarr.exe
```

### UI checks

1. On completing a fresh verification, verify that items with a complete original artist and song title but no MusicBrainz candidates no longer appear in Artist/Song Review.
2. On a row with candidate IDs that produce no usable cards, wait for candidate details. Confirm the app automatically saves its complete source metadata and advances.
3. For an item with incomplete artist/song information, select Add Metadata Manually, fill the missing field, Save; confirm return to Manual Review on the NEXT available item, not a disabled Next button.
4. Open Migration Preview > **Saved for Manual Import**. Verify the source artist, song, album and whether the entry was saved automatically or manually.
5. Verify that previously saved entries stay visible after pressing F5 and restarting the application with the same audit.
6. Verify that these entries are NOT included in selectable Lidarr album counts, and that no Lidarr write/search/download occurred.
7. Verify that Manual Review's original artist/song identity counters do not incorrectly increase when metadata is merely saved.
