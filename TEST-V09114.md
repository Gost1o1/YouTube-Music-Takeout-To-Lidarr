# v0.9.1.14 — Windows test checklist

## One command

Extract the full ZIP to a new folder. Open PowerShell **inside the extracted folder**, stop the older executable if it is running, then run:

```powershell
powershell -ExecutionPolicy Bypass -File .\BUILD-AND-RUN.ps1
```

The script builds Release/win-x64, runs the .NET self-tests, publishes a single-file self-contained EXE, then launches it. It stops on the first failure.

## Complete individual commands (alternative)

```powershell
dotnet build YouTubeMusicToLidarr.csproj -c Release -r win-x64
dotnet run --project YouTubeMusicToLidarr.csproj -c Release -r win-x64 --no-build -- --self-test
dotnet publish YouTubeMusicToLidarr.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
.\publish\YouTubeMusicToLidarr.exe
```

Do not continue after a failed build or self-test.

## Test cases

1. Confirm the top-right version reads `v0.9.1.14`. If you see the older version, close the previous EXE/browser tab and reopen the URL printed by the new EXE.
2. At Manual Review, watch the **Loading candidate names, songs and previews** percentage. It should advance from 0% to 100% based on completed API lookups and disappear once the item is ready.
3. The next review should preload only one item ahead. If Next is disabled while that metadata is still loading, you should see a **Preparing next review** percentage.
4. If HOT SPOT / Hot Spot is **unreviewed**, the only raw candidate ID, and original artist/song metadata is present, the item should be automatically saved as **unverified manual-import metadata** and removed from active Manual Review. Similar sole-exact-name cases should behave the same. No result is promoted to a verified MusicBrainz ID.
5. Ham Sandwich (multiple candidate IDs) and similar competing candidates should **remain reviewable**, not be automatically marked as matching.
6. Differently named tribute groups and collaborations should not appear solely on the strength of artwork or an Apple preview.
7. Visit Migration Preview → **Saved for Manual Import** and confirm the automatically saved items appear with their source metadata, including a distinct single-name/unverified origin when applicable.
8. Confirm F5 retains the correct wizard page. Existing audit data and locally saved decisions must remain unchanged.
9. Check no Lidarr downloads or metadata additions were triggered: this version prepares local metadata/plans only.
