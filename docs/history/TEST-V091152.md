# v0.9.1.15.2 — Tests and Windows smoke check

## Automated offline checks

`tools/offline_v091152_migration_reconciliation.js` verifies:

- Separate MusicBrainz IDs are never merged solely because they share an audio
  preview or artist name.
- Both staging and full inventory rows are retrieved for Migration Preview.
- To Be Added retains its album-level selection list.
- Already in Lidarr includes track metadata without audio and a file-backed
  recording, while Unmatched includes the unresolved Lazlo recording.
- An artist review choice is visible but not promoted into recording confidence.
- An incomplete inventory response fails closed rather than showing empty tabs.
- Browsing the preview never stages an album or sends a Lidarr write.

Other Node tests cover refresh/navigation, source-only automatic saves,
restore/edit, candidate prefetch, manual choices, local staging, and the About
page. Existing .NET self-tests are preserved.

## Short Windows validation

1. Finish any ongoing scan before closing an older running executable.
2. Extract the entire ZIP and run:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\BUILD-AND-RUN.ps1
   ```

3. Prefer a small fixture or saved audit for the UI smoke test. A new process
   does not inherit the previous process's in-memory completed scan.
4. After a read-only Lidarr comparison, check all four Migration Preview tabs.
   Its unmatched rows should be present and the catalog-only items should be
   distinguished from downloaded files.
5. Review Lazlo (or an equivalent artist) and return to Migration Preview.
   Confirm the choice is visible as provisional even if the song and album
   remain unresolved.
6. Refresh Manual Review and Migration Preview, checking tab/position recovery.

**Reminder:** Confirm Local Import Plan stages proposals locally. It does not
download music or send real Lidarr additions.
