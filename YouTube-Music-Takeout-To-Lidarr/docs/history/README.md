# Project history

This folder preserves the earlier change logs, test reports, validation notes,
older instructions and checksum manifests without crowding the front page.

It is an archive, not a list of setup steps. Some older notes refer to file
locations and application behavior that have since changed.

For current installation instructions, use the [main README](../../README.md).
For builds, tests and new releases, use the
[developer guide](../developer/README.md).

The historical SHA256 manifests refer to their **original source ZIP layouts**;
they are not checksums for the reorganized project tree.
