# v0.9.1.15.6 implementation check

The `tools/offline_v091156_lidarr_import.js` regression covers:

- Opening the Finalize screen when no albums are selectable.
- The default no-search mode and the extra explicit consent for searches.
- Requiring selected track-backed albums to enable the search mode.
- Starting a real import request only after the user clicks the final button.
- Request progress, separate Lidarr background task status, and restoration
  after a browser refresh without duplicate write requests.

The C# built-in self-test also verifies that only independently verified,
MusicBrainz-identified artists absent from the Lidarr artist list qualify.

This is an offline regression record, **not** a claim of a successful native
.NET build or successful Lidarr API write. Run the Windows Actions build and
an isolated integration test before publishing or relying on the feature.
