# Windows test instructions — v0.9.1.12

In the extracted source directory:

```powershell
dotnet build YouTubeMusicToLidarr.csproj -c Release -r win-x64
dotnet run --project YouTubeMusicToLidarr.csproj -c Release -r win-x64 --no-build -- --self-test
dotnet publish YouTubeMusicToLidarr.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
.\publish\YouTubeMusicToLidarr.exe
```

Prioritize reviewing an existing finished scan only if running in the same application process. A new EXE does not resume a previous process's in-memory MusicBrainz verification; a new scan will be required.

### Regression tests

1. Refresh on Step 2, on the live verification page, and on Manual Review. The correct page should return without starting an additional scan.
2. Open **Artist Review**: while MusicBrainz candidates are pending, you should see **Loading candidate names, songs and previews…**, and should not be able to select **None of these**. Once loaded, check that Next will not take you to an unprepared next entry.
3. Review **Dick Dale & His Del-Tones** and compare with **Dick Dale and His Del-Tones**: normalized names should be regarded as similar, but a matching name by itself must not automatically verify the artist ID.
4. Review **Lazlo** and other artists with many similar candidate previews; identical Apple audio should be grouped, not shown as independent verification.
5. For an inaccessible YouTube link: check that it is labeled unavailable/inaccessible **without** asserting that it was unlisted. For a playable original YouTube watch link, click **Play original 10s** and click it again to stop/reset. Embedding is not guaranteed; if blocked, the original URL can still be opened.
6. For an entry without usable candidates, click **Add Metadata Manually**, enter artist and song, save, and reopen the record. Confirm that no Lidarr write or file download occurred.
7. Check the .NET application log if the media endpoint returns an error. Real external lookups may have rate limiting or regional restrictions.

### What this update does not do

The album staging and completion workflow is still **local planning only**. MusicBrainz and Lidarr audio acquisition or custom artist creation are not automatically authorized by this version.
